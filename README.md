# ForgeMedia

Public download for **ForgeMedia**, an Android catalogue and video player.

This repository exists for one reason: the source repository is private, and
GitHub answers unauthenticated release lookups against a private repository
with a 404. The app's built-in updater deliberately sends no `Authorization`
header, so its release feed has to live somewhere anonymous requests can
reach. That place is here.

There is no source code in this repository — it hosts published binaries only.

## Installing

1. Download `ForgeMedia.apk` from the link above, or let the app update itself.
2. Allow installs from unknown sources for your browser or file manager when
   Android prompts.
3. Open the APK. An existing install upgrades in place — releases are signed
   with a stable key. Android refuses downgrades, so installing an older build
   needs an uninstall first.

## Verifying the download

Each release also carries `ForgeMedia.json`, whose `apk_size` and `apk_sha256`
are what the updater checks before it installs anything. Confirm the file by
hand the same way:

    Get-FileHash .\ForgeMedia.apk -Algorithm SHA256

Lowercase the result and compare it against `apk_sha256` in
`ForgeMedia.json`. Any mismatch means do not install.

## Updating an installed app

In the app: **Providers → App updates → Check for updates**.

A check costs two small JSON requests — the APK is never downloaded just to
find out whether it is current. Before anything is installed, the download is
verified for HTTPS on a GitHub host, declared size, SHA-256, package name,
`versionCode` (no downgrades), and that its signing certificate is in the
installed app's lineage. Android then asks you to confirm the install.
